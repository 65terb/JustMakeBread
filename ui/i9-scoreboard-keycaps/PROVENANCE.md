# I9 scoreboard keycap asset provenance

- Asset direction: user-mandated replacement for rejected CSS/canvas keycaps and raw/floating tutorial content; final visual adoption remains pending.
- Raster process: deterministic offline raster correction and atlas assembly, generator contract `i9-keycap-raster-v003-black-outline`. Runtime receives PNG bytes only and contains no keycap-shape drawing or border-tint constructor.
- Font: `sources/font/Galmuri11-Bold.woff2`, copied read-only from the current Primary Galmuri bundle; SIL OFL 1.1.
- Palette authority: frame `#34454C`, panel/glyph-dark `#263746`, glyph/surface `#F2F1EA`, key outer border `#000000`, lit fill `#B9F3F5`, disabled fill `#809398`.
- High-resolution sources: individual standard `512x512`, wide `1024x512`; normal, lit and disabled states including blank bases.
- Canonical raster outputs: atlas 1x `2176x384` SHA-256 `3520da92a522b2c6e5be54ad9a51bec1740e1c7ea5a11a3e1a2677ab394711c2`, atlas 2x `4352x768` SHA-256 `9eaba93c5fe6a45c09490c6b554cad458252ef7440780699b56d2487d5696512`; exact rect/UV JSON beside each atlas records the expanded layout. Public runtime consumes only the 1x PNG.
- Border/alpha QA: legacy W/A/S/D/E/SPACE/SHIFT plus current Q/ARROWUP/ARROWLEFT/ARROWDOWN/ARROWRIGHT are independently sampled at 4x source and 1x/2x atlas scales. Standard and wide keys both measure 20 px at 4x, 5 px at 1x, and 10 px at 2x. Every transparent-alpha pixel has zero RGB. See `qa/keycap-border-v003.json` and `qa/keycap-border-comparison-v002-v003.png`.
- `tutorial-panel-v002` is reference/QA-only and must not be copied into `public` or bound as a runtime map. Its fallback aspect reference is `3.8:1.25 = 3.04`.
- The dynamic compositor draws actual atlas keycap image regions and Galmuri labels into each semantic screen surface texture. It never reconstructs key shapes and creates no floating tutorial content.
- Runtime shell boundary: the procedural PhysicalScoreboardTemplate is a fallback. `ScoreboardSurfaceAdapter` supplies semantic `panelSurface`, resolution, aspect and safe area so a future GLB swap does not change content state/layout logic. Each instance owns an independent screen material and texture.
- Integrity: `SHA256SUMS.txt` and `qa/asset-metadata.json` are generated by `sources/build_asset_metadata.py`; corrected sources, atlases, and comparison evidence are reproducible with `sources/regenerate_keycaps_v003.py`.
