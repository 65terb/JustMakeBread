## 1. 공식적으로 확인된 사실

- 행사명은 OpenAI Game Builders Seoul이다.
- Track 1은 온라인 Warm-up Challenge이며, 2026-08-04부터 2026-08-30까지의 일정이 페이지에 표시되어 있다. 예선 접수는 2026-08-04–08-26, 심사는 2026-08-27, 본선 진출작 발표는 2026-08-28–08-30으로 표시되어 있다.
- Track 1 제출작은 브라우저에서 바로 실행되는 웹 빌드 형태여야 하며, 심사위원이 직접 플레이할 수 있는 플레이 링크가 필요하다.
- 플레이 링크는 심사 기간 동안 접속 가능해야 하고, 별도 승인 없이 접근 가능해야 하며, 로그인 필요 시 테스트 계정을 제공해야 한다. 조작법과 실행 방법 안내도 제출 안내에 포함되어 있다.
- Track 1은 코어 플레이 구조에서 재미를 느낄 수 있는 플레이 가능한 프로토타입을 요구한다.
- 팀 구성은 팀당 3명 이하로 안내되어 있으며, 본선 선발 규모는 40팀으로 안내되어 있다.
- 평가 항목으로 Playability, Originality, Codex Collaboration, Release Potential, Presentation이 안내되어 있다.
- 데모 영상은 선택 제출이며, 3분 이내 실제 플레이 영상이 권장된다. Codex 활용 과정도 선택 제출이며, 어디에 사용했는지·어떤 기능을 구현했는지·어떤 문제를 해결했는지·사람이 결정한 부분을 설명할 수 있다.
- 공식 페이지는 수상작의 향후 게임 출시 시 Hive 연동이 권장될 수도 있다고 안내하지만, Track 1 최소 구현의 필수 조건으로 Hive 연동을 명시하지 않는다.

## 2. 내부 일정과 보수적 가정

아래는 공식 규정이 아니라 구현·제출 리스크를 줄이기 위한 내부 운영 기준이다.

- 내부 목표: 2026-08-06 문서와 첫 프로토타입 기반 정리, 2026-08-07 이동·집기·내려놓기 검증, 2026-08-10 생산 사슬의 첫 연결, 2026-08-18 플레이 감각·안정성 정리, 2026-08-24 공개 배포 리허설, 2026-08-26 제출 준비 완료.
- 공식 페이지의 제출 일정이 변경될 수 있다고 보고, 내부 목표는 공식 마감보다 앞당긴다.
- 심사위원은 로그인하지 않고 일반적인 데스크톱 브라우저에서 바로 실행한다고 보수적으로 가정한다. 이 가정은 공식 규정이 지정한 브라우저·운영체제·해상도 규격이 아니다.
- 공개 플레이 링크에는 설명만으로 조작이 이해되도록 조작법을 함께 노출하고, 새로고침 후에도 외부 서비스나 계정 없이 시작할 수 있게 유지한다.
- Vercel은 정적 Vite 빌드를 공개하기 위한 내부 배포 선택지다. Vercel 사용이 대회 공식 요구라는 뜻은 아니다.
- 현재 단계에서는 Hive, 로그인, 백엔드, 결제·상점 기능을 추가하지 않는다. 이는 내부 범위 결정이지 공식 면제나 금지의 해석이 아니다.

## 3. 아직 확인되지 않은 사항

- 공식 규정에서 심사 브라우저·운영체제·모바일 지원 여부, 최소·권장 사양, 네트워크 품질, 패키지 용량, 로딩 시간의 수치 기준은 확인하지 못했다.
- Vercel을 포함한 특정 호스팅 서비스의 허용·권장 여부와 외부 호스팅 비용 처리 방식의 세부 운영 기준은 별도 공지에서 확인해야 한다.
- 심사위원의 플레이 시간, 재시도 횟수, 세부 점수 배점, 제출 링크 장애 시 복구 절차는 확인하지 못했다.
- 제출 기간 이후의 링크·파일 수정 가능 여부와 최종 제출 포맷의 세부 제한은 확인하지 못했다.
- Hive 연동의 실제 심사 가중치, 기술 요구사항, 연동 시점은 확인하지 못했다.

미확인 사항은 결정의 근거로 사용하지 않으며, 공식 공지나 운영진 안내가 생기면 확인일과 출처를 함께 갱신한다.
